# ۰۰ — چشم‌انداز محصول

## ۱. تعریف یک‌خطی

> Finora یک سیستم‌عامل مالی است که تمام جریان پول یک انسان، یک خانواده و یک کسب‌وکار کوچک را
> در یک جای واحد ثبت، تحلیل و پیش‌بینی می‌کند.

## ۲. مسئله‌ای که حل می‌کنیم

امروز کاربر برای مدیریت مالی خود مجبور است بین چند ابزار پراکنده جابه‌جا شود:

| نیاز | ابزار رایج امروز |
|---|---|
| ثبت هزینه شخصی | اپ حسابداری موبایل |
| بودجه‌بندی | YNAB / اکسل |
| دنگ و تقسیم هزینه سفر | Splitwise |
| سبد سرمایه‌گذاری | اپ صرافی + اکسل |
| حساب شرکت کوچک | نرم‌افزار حسابداری سنگین |
| مدیریت شارژ ساختمان | دفترچه / اکسل |
| بایگانی فاکتور و قرارداد | گالری گوشی |
| چک و اقساط | یادداشت و تقویم |

نتیجه: داده‌ها تکه‌تکه‌اند، تصویر واحدی از وضعیت مالی وجود ندارد، و هیچ تحلیلی ممکن نیست.

**Finora همهٔ اینها را در یک مدل داده و یک رابط کاربری واحد جمع می‌کند.**

## ۳. تمایز اصلی (چرا کاربر مهاجرت می‌کند؟)

این‌ها ویژگی‌هایی هستند که رقبا یا ندارند یا ناقص دارند. اینها **قلب محصول** هستند و
نباید به فازهای دور موکول شوند:

1. **ثبت با زبان طبیعی** — «دیروز ۳۵۰ لیر برای شام پرداخت کردم» → تراکنش کامل ساخته می‌شود.
2. **ثبت صوتی** — کاربر حرف می‌زند، تراکنش ثبت می‌شود (FFmpeg → STT → NLP → Transaction).
3. **اسکن رسید با OCR + AI** — عکس قبض → فروشگاه، تاریخ، مالیات، اقلام، ارز، جمع.
4. **جستجوی معنایی** — «هزینه‌های سفر استانبول پارسال»، «همهٔ خریدهای مربوط به ماشین».
5. **تحلیل رفتار مالی** — تشخیص هزینهٔ غیرعادی، روند، پیش‌بینی جریان نقدی.
6. **چند Workspace** — زندگی شخصی، شرکت، ساختمان، سفر، خانواده — کاملاً مستقل.
7. **اشتراک‌گذاری Workspace** با سطح دسترسی (مشاهده / ثبت / مدیریت).
8. **بایگانی سند برای هر رکورد** — فاکتور، قرارداد، عکس، صوت، ویدیو، ZIP.
9. **داشبورد کاملاً شخصی‌سازی‌شونده** با ویجت‌های قابل جابه‌جایی.
10. **چندارزی واقعی** — IRR، TRY، USD، EUR، AED، BTC، ETH، USDT در کنار هم.

## ۴. پرسوناها

| پرسونا | نیاز غالب | ماژول‌های کلیدی |
|---|---|---|
| **علی — کارمند** | فهمیدن اینکه پول کجا رفت | Personal, Budget, Reports, AI |
| **مریم — مادر خانواده** | بودجهٔ خانواده و خرج بچه‌ها | Family, Budget, Alerts |
| **رضا — صاحب فروشگاه کوچک** | فروش، خرید، تنخواه، فاکتور | Business, Documents, Reports |
| **سعید — مدیر ساختمان** | شارژ، بدهکاران، صندوق | Buildings, Alerts, Reports |
| **نیلوفر — مسافر / گروه دوستان** | تقسیم هزینه سفر | Travel, Split Expense |
| **کاوه — سرمایه‌گذار** | ROI طلا، دلار، بورس، کریپتو | Investment, Assets, Reports |

یک کاربر واقعی معمولاً **چند پرسونا هم‌زمان** است — و دقیقاً به همین دلیل به Workspace نیاز داریم.

## ۵. مدل درآمدی

| پلن | مخاطب | نمونه محدودیت |
|---|---|---|
| **Free** | فرد تازه‌وارد | ۱ Workspace، ۲ حساب، بدون AI |
| **Premium** | فرد جدی | Workspace نامحدود، AI، OCR، سرمایه‌گذاری |
| **Family** | خانواده | ۵ عضو، بودجهٔ مشترک |
| **Business** | کسب‌وکار کوچک | فاکتور، کارمند، حقوق، نقش‌ها |
| **Enterprise** | چند شعبه / سازمان | SSO، Audit پیشرفته، SLA |

محدودیت‌ها از طریق یک لایهٔ متمرکز **Entitlements** اعمال می‌شوند، نه `if` پراکنده در کد.

## ۶. محدودهٔ نسخهٔ اول (MVP)

**داخل محدوده:**
Workspace، حساب‌ها، تراکنش، دسته‌بندی چندسطحی، چندارزی، بودجه، گزارش پایه، اسناد، جستجو، احراز هویت، i18n.

**خارج از محدودهٔ MVP (اما در معماری پیش‌بینی‌شده):**
حقوق و دستمزد، مالیات کشور-محور، اتصال مستقیم به API بانک‌ها، بورس Real-time،
اپلیکیشن Enterprise چند-تننتی با SSO.
